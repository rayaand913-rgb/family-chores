# Little Wins

A small family chore board. Open `index.html` in a browser to use it.

## What it does

- Add, edit, complete, and remove chores.
- Track the chore name, date added, assigned family member, and points.
- Filter the list by person or completion status.
- Keep the list in the browser's local storage.

The saved list belongs to the browser and device where it was edited. It does not sync between family members. To share one live list across devices, the app needs a shared data service and family sign-in; GitHub Pages by itself only hosts the website files.

## GitHub Pages

After placing these files in a GitHub repository, enable Pages in the repository's **Settings → Pages** and publish from the `main` branch, root folder. The site will then be available at the Pages URL shown by GitHub.
